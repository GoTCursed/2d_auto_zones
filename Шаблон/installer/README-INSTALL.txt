LiraSlabZones — установка

Что будет установлено:
1. Add-in Revit 2023:
   %APPDATA%\Autodesk\Revit\Addins\2023\LiraSlabZones\
2. Данные (config, families, output):
   %LOCALAPPDATA%\LiraSlabZones\
3. PreviewHost (превью без Revit):
   %LOCALAPPDATA%\LiraSlabZones\tools\

Требования:
- Autodesk Revit 2023 (x64)
- .NET Framework 4.8

После установки:
1. Перезапустите Revit 2023
2. Откройте вкладку LiraSlabZones
3. Семейство зоны доп. армирования выберите из текущего проекта Revit

Права администратора не требуются.
